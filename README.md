# 广东全省医疗设备招标信息汇总平台

面向**标书专员**，用于查看**广东省 21 个地级市**医疗设备招投标公告的纯前端汇总平台（原粤东汕头/潮州数据已完整保留）。

## 功能

- 左右分栏：左侧分类导航 + 右侧搜索 / 列表 / 分页
- 左侧三维导航：**地区**（21 个地级市 / 4 大片区：珠三角·粤东·粤西·粤北）、**设备类别**（内窥镜类 / 彩超·超声设备 / 其他设备）、**公告类型**（招标公告 / 中标结果公告 / 调研·论证公告）
- 公告按**发布时间倒序**排列，最新置顶
- 每条公告展示：标题、所属地区、设备类别、公告类型、预算金额、发布日期
- **关键词搜索**（全局优先，输入即检索全部公告，忽略左侧分类）
- 点击分类导航切换筛选（点击导航会清空搜索，回到该分类视图）
- 点击列表条目弹出**详情预览弹窗**，含【跳转原始公告链接】按钮
- **分页**展示，每页 10 条
- **数据自动更新**：顶部「刷新」按钮可手动重新载入最新数据；页面每 5 分钟也会自动重新拉取；左侧底部显示「更新于 YYYY-MM-DD」

## 运行方式

本项目使用原生 ES Module（`src/main.js` 通过 `<script type="module">` 加载），
浏览器要求模块经 **http(s) 源**加载，因此**不能直接双击 `index.html`**（file:// 会因 CORS 失败）。
本地预览请起一个静态服务（任选其一）：

```bash
# 方式一：Python 自带（无需安装）
python3 -m http.server 8080
# 然后浏览器打开 http://localhost:8080

# 方式二：npm（已提供 serve 脚本）
npm run serve
```

> 注意：页面样式通过 TailwindCSS CDN（`https://cdn.tailwindcss.com`）引入，首次打开需要**联网**。
> 【跳转原始公告链接】指向**真实可打开的官方公告详情页**（中国政府采购网、广东省政府采购网、医院/代理机构官网等），点击会在新标签页打开真实公告，可查看完整正文。
>
> 对外分享请使用 **EdgeOne Pages 固定链接**（部署见 `部署指南.md`）：域名永久不变、内容随每日自动化自动更新；不再使用会因沙箱回收而失效的 cloudstudio 临时链接。

## 数据自动扩充（定时任务）

数据文件 `js/data.js` 由定时自动化任务（每日 09:00 与 15:00 两次）持续维护：联网多源检索**广东省 21 个地级市**医疗设备招投标公告（严格取自官方源：中国政府采购网 ccgp.gov.cn、广东省政府采购网 gdgpo.czt.gd.gov.cn、采联/国义等代理机构官网、各医院官网等），去重合并后写入 `data.js` 并更新 `DATA_UPDATED` 时间戳。写入后经过 `tests/validate-data.cjs` 质量门禁校验（id 唯一、字段完整、日期与链接格式合法），校验不通过则中止发布。随后自动 `git commit + push`，由 EdgeOne Pages 重新部署，固定链接内容始终最新（部署详见 `部署指南.md`）。

## 数据说明

公告内容为**真实数据**：经联网检索整理的 2025–2026 年**广东省 21 个地级市**公开发布的医疗设备招投标公告（持续扩充中，当前 **164 条**）。每条均附**原始公告链接**，点击【跳转原始公告链接】会在新标签页打开对应的官方公告详情页（中国政府采购网、广东省政府采购网、医院/代理机构官网等），可查看完整正文。调研类公告未披露预算的，界面显示「—」。
